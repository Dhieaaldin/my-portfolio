# Dhia Eddine Louati - Portfolio Website (Version 2.0)

Welcome to the second version of my portfolio! This site is a major upgrade from my original static HTML/CSS/JS portfolio — now rebuilt with cutting-edge technologies to showcase my skills and projects in data science, AI, and software development with modern performance and polish.

You can explore my work, skills, and experience, powered by a sleek UI and even an AI chatbot to interact with my portfolio content!

**Live demo:** [https://dhieaaldin.github.io/my-portfolio/](https://dhieaaldin.github.io/my-portfolio/)

---

## Why Version 2?

The original portfolio was a simple, static website built with basic HTML, CSS, and JavaScript. While functional, it lacked modern features, responsiveness, and interactive elements.

Version 2 is a complete redesign using:

- Next.js 16 with the new App Router for fast and scalable React apps  
- TypeScript for type safety and maintainability  
- Tailwind CSS v4 for utility-first styling and responsive design  
- Framer Motion for smooth animations and transitions  
- Static export for zero-cost, reliable hosting on GitHub Pages  

This approach lets me deliver a polished, professional, and interactive portfolio that works perfectly on any device — plus it integrates a powerful RAG-based AI chatbot backend to answer questions about my work in real-time!

---

## Features

- **Modern Tech Stack:** Next.js 16, TypeScript, Tailwind CSS v4, Framer Motion  
- **Fully Static:** Zero-cost hosting with GitHub Pages, optimized for performance  
- **Responsive Design:** Mobile-first and adaptive layout  
- **Dark Mode Support:** Auto theme switching with system preferences  
- **Smooth Animations:** Engaging page transitions and scroll effects  
- **SEO Optimized:** Semantic HTML and meta tags for discoverability  
- **Project Filtering:** Easily browse projects by category and tech stack  
- **AI Chatbot Integration:** Ask questions about my projects and skills right from the portfolio  

---

## Chatbot Integration

This portfolio features a **RAG-powered AI chatbot** backed by a FastAPI server running a MongoDB Atlas vector search. The chatbot can answer your questions about my experience, projects, and skills with sourced and relevant responses — providing an interactive and personalized portfolio experience.

The chatbot endpoint is:  
`https://rag-assistant-backend-v1.onrender.com/api/chat`

Feel free to try it out directly on the portfolio site!
